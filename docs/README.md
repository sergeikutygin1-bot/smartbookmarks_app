## 📝 Contributing to Documentation

When adding new documentation:

1. **Choose the right folder:**
   - Architecture/design docs → `architecture/`
   - Deployment/infra docs → `deployment/`
   - Bug fixes/debugging → `fixes/`
   - Project phases → `phases/`
   - API specs → `api/` or `api/analytics/`
   - Database guides → `database/`
   - iOS docs → `ios/`
   - Security notes → `security/`

2. **Update this README** by adding your new document to the appropriate section above

3. **Update CLAUDE.md** if the document is referenced there

4. **Use clear filenames** with UPPERCASE for visibility (e.g., `GUIDE_NAME.md`)
